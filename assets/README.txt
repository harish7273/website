================================================================================
                    BIRTHDAY WISH - ASSETS DIRECTORY
================================================================================

This folder holds the photos and background music for your website.

1. PHOTOS (assets/p1.jpg to assets/p6.jpg)
   - Replace p1.jpg through p6.jpg with your favorite real photos!
   - Recommended aspect ratio: 4:5 or 1:1 portrait/square (e.g., 800x1000px).
   - Supported formats: .jpg, .jpeg, .png, .webp.
   - If you want more or fewer photos, edit the `photos` array at the top of `script.js`.

2. MUSIC (assets/birthday.mp3)
   - Place your favorite song or birthday tune here named "birthday.mp3".
   - If no mp3 is provided, the website automatically plays an enchanting
     synthesized music-box chime tune using the Web Audio API, so it never fails!

Enjoy celebrating!
